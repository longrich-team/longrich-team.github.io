# Каталог Longrich 2026

**Адрес: https://longrich-team.github.io**

Чистый каталог: только товары. Без кнопок заказа, без контактов.

## Файлы

- `index.html` — страница каталога
- `data.js` — все товары, цены и описания. **Правится здесь.**
- `img/` — фотографии товаров

## Как обновить

```
cd ~/Desktop/longrich-catalog/longrich-team
git add -A
git commit -m "обновил цены"
git push
```

Через минуту изменения появятся на сайте.
